
# E-Commerce Sales Data Analysis

## Project Overview
An end-to-end beginner/intermediate data analysis project using Python, Pandas, NumPy, SQL and Matplotlib.

The project generates a realistic synthetic e-commerce dataset and answers business questions about revenue, customers, products, cities, payment methods and monthly sales.

## Tech Stack
- Python
- NumPy
- Pandas
- SQL / SQLite
- Matplotlib
- Git & GitHub

## Dataset
The project creates:
- `customers.csv`
- `products.csv`
- `orders.csv`
- `order_items.csv`

No external dataset is required.

## Business Questions
1. What is the total revenue?
2. How many orders were delivered?
3. What is the average order value?
4. Which products generate the most revenue?
5. Which product categories generate the most revenue?
6. How does revenue change month by month?
7. Who are the top customers?
8. Which payment methods are most popular?
9. What is the order-status distribution?
10. Which cities generate the most revenue?

## How to Run

```bash
pip install -r requirements.txt
python analysis.py
```

The script creates all datasets and analysis outputs automatically.
